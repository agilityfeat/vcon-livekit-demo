How to use this viewer
  • Bundled sample — loads samples/vcon-full.sample.json. Needs the page to be served over http (e.g. python3 -m http.server); under file:// the browser may block the fetch, so use the file picker instead.
  • Local file — pick any vCon JSON from disk; it is read in the browser (no upload).
  • URL — paste a URL or relative path to a vCon JSON and load it.
  • Physician / Analyst toggle — Physician shows the full record (transcript, summary, clickable medications that seek the audio). Analyst shows the redacted record, visibly linked to the full one via the standard redacted field.

🩹 Demo: no auth; role views are a client-side toggle. → Production: role-gated access control.
